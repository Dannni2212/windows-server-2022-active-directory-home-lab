This folder contains architecture diagrams for the Windows Server 2022 Active Directory Home Lab.

These diagrams illustrate the logical layout of the environment, including:

- Oracle VirtualBox
- Windows Server 2022 (DC01)
- Windows 10 Client (PC01)
- Active Directory Domain Services
- DNS
- DHCP
- DFS Namespace
- Windows Server Backup
- WSUS

Additional diagrams will be added as the lab expands into Microsoft Entra ID, Microsoft 365, Intune, and Azure.
